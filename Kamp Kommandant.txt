NODE.JS AND JAVASCRIPT
----------------------
node -v
    Display the installed Node.js version.

npm -v
    Display the installed npm version.

node app.js
    Execute app.js using Node.js. This is for JavaScript that does not
    depend on browser features such as document, window or localStorage.


REACT AND VITE
--------------
npm create vite@latest my-app -- --template react
    Create a new React project named "my-app" using Vite.

cd my-app
    Enter the newly created project directory.

npm install
    Install the dependencies listed in package.json.

npm run dev
    Start the Vite development server.

npm run build
    Create an optimized production build.

npm run preview
    Preview the production build locally.

npm run
    List the scripts defined in package.json.


REACT ROUTER
------------
npm install react-router-dom
    Install React Router DOM for navigation between React pages.

npm list react-router-dom
    Check whether react-router-dom is installed.


REDUX
-----
npm install @reduxjs/toolkit react-redux
    Install Redux Toolkit and the React-Redux bindings.

npm list @reduxjs/toolkit
    Check whether Redux Toolkit is installed.

npm list react-redux
    Check whether React-Redux is installed.


OTHER USEFUL NPM COMMANDS
-------------------------
npm init -y
    Create a package.json file with default settings.

npm install package-name
    Install a package as a project dependency.

npm install -D package-name
    Install a package as a development dependency.

npm uninstall package-name
    Uninstall a package.

npm update
    Update installed packages within the version ranges allowed by package.json.

npm list
    List installed packages.

npm list --depth=0
    List top-level installed packages.

npm cache verify
    Verify the npm cache.


VS CODE
-------
code .
    Open the current directory in Visual Studio Code.

code filename.js
    Open a specific file in Visual Studio Code.

code . --new-window
    Open the current directory in a new VS Code window.


STOPPING A RUNNING SERVER
-------------------------
Ctrl + C
    Stop the currently running development server or foreground process.


COMMON WORKFLOWS
----------------

1. BASIC JAVASCRIPT PROJECT
    mkdir StudentManagement
    cd StudentManagement
    code .
    Create index.html, style.css and script.js in VS Code.
    Open index.html in a browser, or use the Live Server extension.

2. CREATE AND RUN A REACT PROJECT
    npm create vite@latest StudentApp -- --template react
    cd StudentApp
    npm install
    npm run dev

3. CREATE A REACT ROUTER PROJECT
    npm create vite@latest StudentPortal -- --template react
    cd StudentPortal
    npm install
    npm install react-router-dom
    npm run dev

4. CREATE A REDUX PROJECT
    npm create vite@latest ExpenseApp -- --template react
    cd ExpenseApp
    npm install
    npm install @reduxjs/toolkit react-redux
    npm run dev

5. CREATE A PROJECT USING BOTH ROUTER AND REDUX
    npm create vite@latest MyApp -- --template react
    cd MyApp
    npm install
    npm install react-router-dom @reduxjs/toolkit react-redux
    npm run dev


IMPORTANT NOTES
---------------
- Run npm install from the project directory containing package.json.
- You only need to create a project once. When reopening it, use:
      cd project-folder
      npm run dev
- Basic HTML/CSS/JavaScript projects do not require npm or Vite.
- Browser-based JavaScript using document, window or localStorage must run
  in a browser, not directly with node app.js.
- If a Vite server is already running, press Ctrl + C to stop it.
- If "code" is not recognized, open the folder from VS Code using
  File > Open Folder.
